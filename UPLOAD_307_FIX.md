# UPLOAD 307 REDIRECT FIX

**Date:** February 03, 2026  
**Issue:** `ECONNRESET` error during file upload due to 307 Temporary Redirect  
**Status:** ✅ **FIXED**

---

## 🐛 ROOT CAUSE

**Backend Logs:**
```
INFO: 127.0.0.1:63151 - "POST /api/v1/upload HTTP/1.1" 307 Temporary Redirect
```

**Frontend Logs:**
```
Sending Request to the Target: POST /api/v1/upload
proxy error Error: read ECONNRESET
```

**Analysis:**
- Frontend was calling `/api/v1/upload` (WITHOUT trailing slash)
- Backend route requires `/api/v1/upload/` (WITH trailing slash)
- FastAPI automatically redirects 307, which breaks multipart/form-data stream
- Connection drops → `ECONNRESET`

---

## 🔧 FIX APPLIED

**File:** [web/src/utils/fileDetection.ts](web/src/utils/fileDetection.ts)

**Changed 9 endpoint definitions** from:
```typescript
endpoint: '/api/v1/upload'      // ❌ Missing trailing slash
endpoint: '/api/v3/yield/upload' // ❌ Missing trailing slash
```

**To:**
```typescript
endpoint: '/api/v1/upload/'      // ✅ With trailing slash
endpoint: '/api/v3/yield/upload/' // ✅ With trailing slash
```

**Affected File Types:**
- COOISPI (Production Orders)
- MB51 (Material Movements)

- ZRSD002 (Sales Orders)
- ZRSD004 (Delivery)
- ZRFI005 (AR Aging)

## 📝 LESSONS LEARNED

1. **Multiple Upload Paths:** The codebase has 2 upload mechanisms:
   - `uploadAPI.uploadFile()` in [api.ts](web/src/services/api.ts) - ✅ Had trailing slash
   - Smart detection in [DataUpload.tsx](web/src/pages/DataUpload.tsx) - ❌ Missing trailing slash

2. **Search Scope:** Initial audit only checked `api.ts`, missed `fileDetection.ts`

3. **FastAPI Behavior:** FastAPI's automatic 307 redirect breaks multipart/form-data streams

4. **Fix:** **Always use trailing slashes** for FastAPI POST endpoints to avoid redirects
